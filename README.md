# 🎵 Spotify Data Analysis 🎵

## 📌 Overview
This project analyzes **Spotify streaming data**, uncovering trends in **albums, artists, and tracks** over time using **Power BI, DAX, and data modeling**.

## 📊 Key Insights
- 📀 **Albums Trends** – Top albums and listening patterns.
- 🎤 **Artists Analysis** – Most played artists and their influence.
- 🎶 **Track Insights** – Understanding song engagement.
- 📅 **Listening Behavior** – Peak hours, weekdays vs. weekends.
- 📈 **Year-over-Year Trends** – How music preferences evolve.
